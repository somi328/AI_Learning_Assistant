# AI-Driven Emotion Detection & Personalized Learning Support Platform

## 📖 Overview

The AI-Driven Emotion Detection & Personalized Learning Support Platform is an intelligent learning assistant that detects learners' emotions from text input using BERT and BiLSTM deep learning models. Based on the detected emotion, Google Gemini AI generates personalized learning guidance, helping students overcome confusion, frustration, boredom, curiosity, and other learning challenges.

---

## 🚀 Features

- Emotion Detection using BERT
- Emotion Detection using BiLSTM
- Personalized AI Responses using Google Gemini
- Session History
- User-Friendly Streamlit Interface
- Real-Time Predictions
- AI Learning Guidance
